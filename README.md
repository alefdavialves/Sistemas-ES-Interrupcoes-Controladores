# Sistemas de E/S, Interrupções e Controladores

Repositório do trabalho acadêmico de Arquitetura de Computadores, desenvolvido com uma prova de conceito no simulador Wokwi para comparar os mecanismos de polling e interrupções de hardware.

## Experimentos

- **Teste A:** Polling sem evento.
- **Teste B:** Polling com evento.
- **Teste C:** Interrupção habilitada.
- **Teste D:** Interrupção desabilitada.

## Organização

- `Codigos_Fonte/`: códigos utilizados nos experimentos.
- `Capturas_VCD/`: arquivos VCD gerados pelo analisador lógico do Wokwi.
- `Prints/`: registros visuais e evidências dos testes realizados.

## Ambiente utilizado

- Simulador: Wokwi.
- Placa: Arduino Uno, baseada no ATmega328P.
- Linguagem: C/C++ do framework Arduino.
- Instrumentação: Serial Monitor e analisador lógico do Wokwi.

Os arquivos deste repositório complementam o relatório técnico-acadêmico, permitindo consultar os códigos e as evidências utilizadas na análise dos resultados.
